# Макет портфолио v3

HTML-прототип сайта до сборки production-версии в корне репозитория.

## Отличия от production

| | Макет | Production (`/index.html`) |
|---|--------|---------------------------|
| Showreel | Ссылка на локальный файл | Встроенное видео + автозапуск |
| Деплой | Только локально | GitHub Pages |
| Баннер | «МАКЕТ v3» | — |

## Как открыть

```bash
open portfolio-mockup/index.html
```

Или через локальный сервер из корня репозитория:

```bash
python3 -m http.server 8080
# → http://localhost:8080/portfolio-mockup/
```
